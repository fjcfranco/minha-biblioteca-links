Gerencie a sincronização, os backups e a conexão com o Google Drive.

☁ Google Drive · sincronização direta

Não conectado

Requer Google Cloud: habilite a Drive API, crie um cliente OAuth do tipo Aplicativo da Web e autorize a origem HTTP(S) desta página. O Drive armazenará biblioteca-links.json. O acesso usa somente os arquivos criados por este aplicativo. A autorização é temporária. Se ativar a opção de manter conexão, um token de acesso será guardado neste dispositivo até expirar (normalmente menos de uma hora). Não ative em computadores compartilhados.

O cadastro local funciona mesmo sem conexão com o Google.

Importação e exportação

A importação comum substitui apenas os dados locais e poderá provocar conflitos com o Drive. Para voltar a um backup antigo, use Restaurar biblioteca completa. Essa operação substituirá também o cadastro sincronizado no Google Drive. Faça isso apenas em um dispositivo; depois use Recarregar do Drive nos demais.

Armazenamento local ativo

Os registros são salvos automaticamente no IndexedDB. Ao conectar o Google, são sincronizados com o Drive durante o uso, quando houver rede e autorização válida. Abrir/Salvar arquivo JSON é uma opção adicional de backup manual. Se o mesmo registro for alterado em dois dispositivos desde a última sincronização, o aplicativo pedirá para escolher a versão. Mantenha backups: não há bloqueio transacional entre dispositivos.

Gerenciamento de tags

Renomeie, mescle ou remova uma tag de todos os registros ativos. As alterações serão sincronizadas com o Google Drive.

A remoção afeta apenas a tag; nenhuma URL é excluída. Faça backup antes de alterações em lote.

Gerenciamento de coleções

Organize links independentemente das tags. Uma URL pode pertencer a várias coleções.

Nenhuma URL será excluída. Faça backup antes de operações em lote.

Importar favoritos do navegador

A importação acrescenta novas URLs, sem modificar ou excluir registros existentes. Links já cadastrados serão ignorados.
